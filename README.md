Write the funniest one-line warning label for a time machine in 120 characters or fewer. An AI judge reads the labels two at a time and keeps the funnier one. Free to enter, $2 to the funniest line.

The entry is a tiny stdlib-only Python program (`main.py`). It validates one warning label — 1–120 characters, a single line, not whitespace-only — then writes it to `/output/entry.txt` and reads it back to prove the write.
